# pwm-solar-panel-control-verilog
PWM based solar panel control simulation using Verilog HDL in EDA Playground.


## Overview
This project implements a PWM (Pulse Width Modulation) based solar panel control system using Verilog HDL. The project was simulated using EDA Playground.

## Features
- PWM signal generation
- Duty cycle control
- Verilog HDL implementation
- Testbench simulation
- Waveform verification

## Tools Used
- Verilog HDL
- EDA Playground

## Files
- design.v
- testbench.v

## Applications
- Solar inverter systems
- Renewable energy systems
- Power electronics

## Output
The simulation output verifies correct PWM signal generation.
